# INDTOOLS Product Catalog

This is the catalog shipped with the `indtools_pwa` app. It is created by `indtools_pwa/setup_products.py` and served to the PWA through Frappe `Webshop` (`webshop.webshop.api.get_product_filter_data`) and the indtools PWA's own REST APIs.

**Total:** 8 item groups, 64 products + 8 category items = **72 items**.

## Item Prices

The deploy script (`deploy/setup_webshop.py`) creates `Item Price` records for every item on the `Standard Selling` price list, deterministically generated as 25..220 INR in steps of 5 (seeded from the item code hash) — so every deployment gets identical prices without manual data entry.
